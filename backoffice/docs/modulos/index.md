# Módulos

El sistema se navega con dos barras: la de la izquierda lista los **módulos**;
la que se abre al lado, las **secciones** del módulo activo. Es la misma
estructura en todas las verticales Karma.

| Módulo                                      | Secciones                                                                                                       | Quién lo usa    |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------- |
| **[Inicio](/modulos/inicio)**               | El taller hoy · [Tablero de bahías](/modulos/tablero)                                                           | Todos           |
| **Taller**                                  | [Órdenes](/modulos/ordenes) · [Detenidas](/modulos/detenidas) · [Carga de técnicos](/modulos/tecnicos) · Bahías | Asesor, técnico |
| **[Clientes](/modulos/clientes)**           | Vehículos · Clientes · [Citas](/modulos/citas)                                                                  | Asesor          |
| **[Catálogo](/modulos/catalogo)**           | Servicios y baremos · Planes de mantenimiento                                                                   | Asesor, admin   |
| **[Almacén](/modulos/almacen)**             | Repuestos · Movimientos                                                                                         | Almacén         |
| **Admin**                                   | Producción · Facturación · Usuarios · Bitácora                                                                  | Administrador   |
| **[Configuración](/modulos/configuracion)** | Taller · Sedes · Motivos                                                                                        | Administrador   |

## Lo que comparten todas las pantallas

- **Buscador global.** Se abre desde la cabecera y entiende secciones, órdenes
  y placas. Es la forma más rápida de llegar a cualquier sitio.
- **Selector de taller.** Arriba, permanente: todo lo que se ve por debajo
  pertenece a la sede activa.
- **Modo claro y oscuro.** El taller de día y el de noche.
- **Exportación.** Los listados se bajan a CSV o Excel con las columnas que se
  están viendo.
- **El estado nunca se dice solo con color.** Siempre color + símbolo +
  palabra, porque estas pantallas se miran de lejos y con las manos sucias.
